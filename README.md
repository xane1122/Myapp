# MyApp Beta

SwiftUI + WKWebView iOS Beta shell for https://xanelove.com.

- Display name: MyApp Beta
- Bundle ID: com.xanelove.myapp.beta
- Old unsigned IPA Bundle ID: com.example.MyWebApp
- Minimum iOS: 16
- GitHub Actions builds an unsigned arm64 iPhoneOS IPA for SideStore signing.

The complete maintainable Xcode project, tests, build workflow, and background-result API proposal will be committed next. No production VPS changes are included.
